# Website Project Requirements

## Overview
Build a modern landing page for a coffee shop named "CodeBrew".

## Features
1. **Hero Section**: Large background image, headline "Fuel Your Code", and a "Order Now" button.
2. **Menu Grid**: Display 4 types of coffee (Espresso, Latte, Cappuccino, Mocha) with prices.
3. **Contact Form**: Name, Email, and Message fields.
4. **Dark Mode**: A toggle in the navbar to switch themes.

## Technical Constraints
- Use semantic HTML5.
- Vanilla JavaScript for interactions.
- Responsive CSS (Mobile First).
